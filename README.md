# PF2e Avatars - Battle forms for the Avatar spell
- Adds a compendium containing Battle form effects for the Avatar spell for each deity (when the data is available) that you can drag on your divine spellcaster.
- If you have the [PF2e Tokens: Character Gallery](https://paizo.com/products/btq056ko?Pathfinder-Tokens-Character-Gallery) and/or [PF2E Tokens: Myth and Magic](https://paizo.com/products/btq0do4l?Pathfinder-Tokens-Myth-and-Magic) modules, the tokens from these modules will be used for the avatar transformation.
