# PF2e Avatars - Battle forms for the Avatar spell
- Adds a compendium containing Battle form effects for the Avatar spell for each deity (when the data is available) that you can drag on your divine spellcaster.
- If you have the [PF2e Tokens: Character Gallery](https://store.paizo.com/pathfinder-tokens-character-gallery-foundry-vtt-code) and/or [PF2E Tokens: Myth and Magic](https://store.paizo.com/pathfinder-tokens-myth-and-magic-foundry-vtt-code) modules, the tokens from these modules will be used for the avatar transformation.
